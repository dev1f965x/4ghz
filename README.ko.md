# 4ghz

[English](README.md) | 한국어

원신, 붕괴: 스타레일, 젠레스 존 제로의 일정, 리딤 코드, 반복 숙제 캘린더를 보여 주는 비공식 Windows 앱입니다.

4ghz는 HoYoverse와 제휴하거나 승인받지 않은 앱입니다. 원신, 붕괴: 스타레일, 젠레스 존 제로는 각 권리자의 상표입니다.

## 개발

이 앱은 Windows 11에서 개발합니다. 먼저 다음을 설치하세요.

- Visual Studio Build Tools와 "C++를 사용한 데스크톱 개발" 워크로드
- rustup으로 설치한 Rust
- 이 저장소에 고정된 Node.js와 pnpm 버전을 설치하는 mise

명령은 [README.md](README.md#development)의 표를 따릅니다.
