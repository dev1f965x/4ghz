# 4ghz

English | [한국어](README.ko.md)

An unofficial Windows app with schedules, redeem codes, and a chore calendar for Genshin Impact, Honkai: Star Rail, and Zenless Zone Zero.

4ghz is not affiliated with or endorsed by HoYoverse. Genshin Impact, Honkai: Star Rail, and Zenless Zone Zero are trademarks of their respective owners.

## Development

The app is developed natively on Windows 11. Install these first:

- Visual Studio Build Tools with the "Desktop development with C++" workload
- Rust through rustup
- mise, which installs the Node.js and pnpm versions pinned in this repository
